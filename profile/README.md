**Factorio servers, community tools, and open-source infrastructure since 2017.**

We build and operate tools that make Factorio multiplayer easier to host, manage, and enjoy. Our projects cover server administration, Discord integration, community safety, map generation, networking, and public web services.

## Featured projects

| Project | What it does |
| --- | --- |
| [FactMapGen](https://github.com/M45-Science/FactMapGen) | Web editor and previewer for Factorio map generation and map settings. |
| [ChatWire](https://github.com/M45-Science/ChatWire) | Bridges Factorio and Discord chat and provides server-management tools. |
| [SoftMod](https://github.com/M45-Science/SoftMod) | Scenario scripts used by M45 Science Factorio servers. |
| [FactorioServerBrowser](https://github.com/M45-Science/FactorioServerBrowser) | Cached, web-accessible Factorio multiplayer server browser. |
| [DownloadProxy](https://github.com/M45-Science/DownloadProxy) | Caching proxy for Factorio downloads and mod updates. |

## Factorio tools and community resources

| Project | What it does |
| --- | --- |
| [FactBanSync](https://github.com/M45-Science/FactBanSync) | Fetches and merges ban lists from multiple sources. |
| [FactorioCommunityList](https://github.com/M45-Science/FactorioCommunityList) | Public directory of Factorio communities that publish ban lists. |
| [QuickBanCombine](https://github.com/M45-Science/QuickBanCombine) | Combines multiple `ban-list.json` files. |
| [QuickbarExchange](https://github.com/M45-Science/QuickbarExchange) | Compact exchange format for Factorio quickbars. |
| [MapArchiveCleaner](https://github.com/M45-Science/MapArchiveCleaner) | Removes obsolete scenario and softmod data from old map archives. |
